# DESIGN — bozza dell'applicazione

Inserisci qui la bozza che deve guidare il frontend definitivo. Sono accettati:

- uno o più file HTML/CSS/JavaScript;
- un progetto Next.js, React, Vue, Svelte o altro framework;
- immagini, icone e asset accompagnati dalle relative condizioni d'uso;
- `DESIGN-NOTES.md` con flussi, stati o comportamenti non visibili nella bozza.

Questa cartella è un input di progetto: gli agenti la analizzano ma non la modificano.
Il codice di produzione viene costruito in `frontend/` con la tecnologia approvata.
Non inserire segreti, `node_modules`, output di build o cache.

Da questa bozza la fabbrica estrae il linguaggio visivo (`design_language` in
`blueprint/frontend.yaml`) e il piano ricava i task di sviluppo UX/UI: token e shell,
schermate fedeli, stati e rifinitura. Più completa è la bozza, più fedele è il prodotto.
